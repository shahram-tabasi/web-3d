## Posting checklist

1. **Bio link first:** profile → Edit profile → Links → `https://simorghai.com/insights/from-design-to-delivery-one-thread`
   (the caption says «لینک در بیو»; links inside captions are not clickable).
2. **Post:** + → Post → select `post-1` … `post-7` in order → keep the 4:5 crop (do not
   let it crop to square) → paste the caption → Advanced settings: write the alt text
   (below) → Share.
3. **Stories** (after the post is live):
   - `story-1.jpg` as is.
   - `story-2.jpg` as is; optionally add the new post with the paper-plane button
     (Share → Add to story) instead.
   - `story-3.jpg`: add the **Link** sticker
     (`https://simorghai.com/insights/from-design-to-delivery-one-thread`, text «مطالعه مقاله»)
     and place it under the arrow.
4. **Highlight:** add the three stories to a highlight «سیمرغ» so they stay on the profile.
5. **Pin** the post to the top of the profile (… → Pin to your profile).

Alt text for the post: «معرفی سیمرغ: Design Suite برای مهندسان، Simorgh ERP به‌عنوان سابقه واحد و Kara برای همه سازمان؛ از نقشه مهندس تا امضای مشتری.»
